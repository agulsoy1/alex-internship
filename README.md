# NFT Marketplace

A full-stack NFT marketplace developed during my software development internship using React and Firebase.

## Live Demo

[View the live application](https://alex-internship-uih7.vercel.app/)

## Overview

This project is a web-based NFT marketplace that allows users to browse and interact with digital assets through a responsive and interactive interface. Firebase provides authentication and backend data services, while React is used to build the frontend application.

## Tech Stack

* React
* JavaScript
* Firebase
* Firebase Authentication
* Firestore
* HTML
* CSS

## Features

* User authentication
* NFT marketplace browsing
* NFT detail pages
* Firestore database integration
* Firebase Authentication
* Responsive user interface
* Interactive React components

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/agulsoy1/alex-internship.git
cd alex-internship
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
